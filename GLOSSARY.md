# Portfolio

Danila Lutsai's personal portfolio site: a handful of pages that introduce Danila, the technologies they work with, and how to get in touch.

## Language

### Pages

**Page**:
One destination of the site that a visitor reaches by URL and that renders between the navigation and the footer.
_Avoid_: View, screen, route (when meaning what the visitor sees)

**Main page**:
The landing Page at the site root that introduces Danila.
_Avoid_: Home, home page, index

**About page**:
The Page describing Danila's background.

**Techs page**:
The Page listing the technologies Danila works with.
_Avoid_: Skills, stack

**Contact page**:
The Page with the contact form and ways to get in touch.

**Not Found page**:
The Page shown for any URL that matches no other Page, telling the visitor the link is wrong and offering a way back to the Main page.
_Avoid_: 404 page, error page

**Attempted path**:
The part of the URL after the site's base path (including query and hash) that a visitor tried to open and that matched no Page.
_Avoid_: Bad URL, broken link

### Layout

**Navigation**:
The bar at the top of every Page linking to the Main, About, Techs and Contact pages.
_Avoid_: Header, navbar, menu

**Footer**:
The block at the bottom of every Page with explore links, social links, dependencies and learning journey.
